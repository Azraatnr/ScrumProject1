# Scrum Project 1

### User Stories:

1. As a User, I want to be able to log in, so I can use my account.
2. As a User, I want to be able to post comments under posts and see them at a specific place, because I want to be able to look at them later.
3. As a User, I want to be able to share my posts on different apps (Whatsapp, Twitter, Instagram etc).
4. As Admin, I want to be able to delete posts and comments, because they could be harmful.
5. As a User, I want to be able to change and save my profile page, so I can make changes to my profile.
6. As a User, I can follow and see my following's posts on the homepage, because I want to see their posts.
7. As a User, I want to be able to like and dislike comments, because I want to show my opinion this way.



### Functions>
- You can post on the platform, and you can also comment and like and dislike comments.
- You can make an account and log in when you already have one.
- You can share your posts on diffrent apps.
